# 我完成了什么

## 触发条件

需要对特定时间段（例如：昨天、最近 3 天或上周）完成的工作做一份简短、高信号的汇总。

## 工作流

1. 把请求的时间窗口解析为具体日期。
2. 读取该时间段内由当前 git 用户邮箱提交的 commit。
3. 排除 merge commit 和未提交的改动。
4. 把最重要的已交付改动综合成一份简明的状态更新。
5. 在最终汇总中写明实际使用的日期范围。

## 护栏

- 极度简洁、信息密集。
- 优先写实质性的行为或架构改动。
- 略去纯装饰性的改动（格式化、import、小重命名）。
- 不要推断意图或动机。从功能角度描述改动。

## 输出

- 一段适合用作状态更新的简短汇总
- 真实日期范围
- 可选：仅限重大改动的 2-5 条要点
