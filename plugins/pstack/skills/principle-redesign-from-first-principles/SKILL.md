# 从第一性原理重新设计（Redesign From First Principles）

整合一个变更时，不要把它外挂到既有设计上。重新设计，就当这个需求从一开始就在。

- 读所有受影响的文件，理解当前设计
- 问："如果带着这个新需求从零写起，我们会造什么？"
- 把变更传播到每一处引用：类型、文档、示例、理由章节
- 先想清楚整个重设计，再增量交付

这是在既有设计中整合变更时保住选择余地的方法。
